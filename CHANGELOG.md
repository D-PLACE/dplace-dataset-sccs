# Changes

Earlier versions of this dataset have been released as part of the
[D-PLACE/dplace-data](https://doi.org/10.5281/zenodo.596376) dataset.


## [v3.3]

Removed two categories from variables SCCS213 and SCCS215 (related to marital residence), which
were added by D-PLACE. Merged the corresponding coded values into the ten categories given
in the source. Recomputed the automatically derived variable SCCS214.


## [v3.2]

Dataset re-created using Glottolog v5.2 as reference.


## [v3.1]

- Dataset re-created using Glottolog v5.0 as reference.


## [v3.0]

The D-PLACE data was rearranged to make it possible to curate constituent
datasets independently.
